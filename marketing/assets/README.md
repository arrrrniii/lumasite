# Marketing photograph assets

These original illustrative photographs were generated with the built-in `image_gen` tool. The tool did not disclose a model identifier. They illustrate a creative working environment; they do not depict identified customers or provide testimonials.

The unchanged source PNGs remain alongside the delivery files. Full prompts, source paths, original hashes and generation metadata are in [image-generation.json](image-generation.json) for the hero and [founder-generation.json](founder-generation.json) for the founder portrait. LumaSite does not require a remote image service to serve these files.

WebP delivery variants were produced with Sharp using quality 85, effort 6, ordinary proportional resizing only and no image generation or content alteration. The hero retains its full source width; its mobile variant and the founder delivery variant are 900 pixels wide.

## Original blue email hero, version 2

`mail-hero-v2.png` is a new, original 3D product scene generated with the built-in `image_gen` tool for the dark blue SendMailOS website. It shows a sculptural open cobalt envelope, blank ivory message sheets, and frosted panels against a navy studio. The right-center composition leaves the left side clear for HTML headline text. There are no people, customer identities, text, logos, interface metrics, or watermarks in the artwork.

The full prompt, default generation-source path, inspection notes, hashes, and processing metadata are preserved in [mail-hero-v2-generation.json](mail-hero-v2-generation.json). The PNG is unchanged from generation. Sharp produced the delivery files with quality 85 / effort 6 WebP encoding and proportional resizing only; no cropping, enlargement, retouching, or recoloring was performed. Use CSS positioning to adapt the composition to mobile.
